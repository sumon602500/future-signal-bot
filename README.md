## ✨ বৈশিষ্ট্য

- **🎯 OTC মার্কেট এবং BLACKOUT সিগন্যাল** - দুটি বাজার মোড

  - AI FILTER (প্যাটার্ন রিকগনিশন)
  - TREND FILTER (মার্কেট মোমেন্টাম)
  - HUMAN BRAIN (ইনটুইশন-ভিত্তিক লজিক)
- **📱 টেলিগ্রাম ইন্টিগ্রেশন** - সরাসরি সিগন্যাল পাঠান
- **⏱️ কাস্টম টাইম উইন্ডো** - আপনার নিজস্ব সময় নির্ধারণ করুন
- **🔄 রিজেনারেট অপশন** - যেকোনো সময় নতুন সিগন্যাল পান
- **🎨 রঙিন CLI ইন্টারফেস** - সুন্দর এবং ব্যবহারকারী-বান্ধব

## 📋 প্রয়োজনীয়তা

- Python 3.7+
- pip (Python প্যাকেজ ম্যানেজার)
- একটি টেলিগ্রাম বট (ঐচ্ছিক কিন্তু সুপারিশকৃত)

## 🚀 ইনস্টলেশন

### ১. রিপোজিটরি ক্লোন করুন

```bash
git clone https://github.com/sumon602500/future-signal-bot.git
cd future-signal-bot
```

### ২. ভার্চুয়াল এনভায়রনমেন্ট তৈরি করুন (ঐচ্ছিক কিন্তু সুপারিশকৃত)

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS/Linux
python3 -m venv venv
source venv/bin/activate
```

### ৩. ডিপেন্ডেন্সি ইনস্টল করুন

```bash
pip install -r requirements.txt
```

### ৪. `.env` ফাইল তৈরি করুন

`.env.example` কপি করুন এবং `.env` নাম দিন:

```bash
cp .env.example .env
```

তারপর `.env` ফাইলটি খুলুন এবং আপনার টেলিগ্রাম তথ্য যোগ করুন:

```env
TELEGRAM_BOT_TOKEN=your_actual_bot_token_here
TELEGRAM_CHAT_ID=your_actual_chat_id_here
LOG_FILE=telegram_bot.log
USE_EMOJI=true
```

## 🔐 টেলিগ্রাম বট কনফিগারেশন

### টেলিগ্রাম বট টোকেন কীভাবে পান?

1. **@BotFather** কে টেলিগ্রামে খুঁজুন
2. `/newbot` কমান্ড ব্যবহার করুন
3. আপনার বটের নাম দিন (যেমন: "FutureSignalBot")
4. আপনার বটের ইউজারনেম দিন (যেমন: "future_signal_bot")
5. **BotFather** আপনাকে একটি টোকেন দেবে
6. সেই টোকেনটি `.env` ফাইলে পেস্ট করুন

### চ্যাট আইডি কীভাবে পান?

1. আপনার বটকে একটি বার্তা পাঠান
2. ব্রাউজারে এই URL খুলুন:
   ```
   https://api.telegram.org/botYOUR_BOT_TOKEN/getUpdates
   ```
3. `"chat":{"id":YOUR_CHAT_ID}` খুঁজুন
4. সেই আইডি `.env` ফাইলে পেস্ট করুন
